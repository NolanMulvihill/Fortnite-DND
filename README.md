# Fortnite-DND
Creating a DND one shot campaign taking inspirtiaon for the FPS game fortnite

Originally got the idea by my DND wanting everyone to create a DND one shot. One person had all of our characters teleport into their world and this then sparked my idea. One of the biggest things I hear about fornite is about just how many different media franchises. That allowed me to grow my idea.

The Idea:
Have all players think the game will be set in different settings/expansions and create their characters based on those. Implement all those enviornments/expansions into the singualr world. Then just drop them into the world and have that revealed.

Mechanics:
Map with a mix from all settings/expansions
Create an inventory system where the items are actually related to the classes and species
Chest system for items
Storm system to progress the story and make limited exploration
A way to create enemies becaause it would be players with items and not neccesialry monsters tho can include some
